How it works

From message to meaningful category.

The service keeps routing, request handling, model communication, validation, and persistence separated for maintainability and testing.

1

React client

Collects customer text and sends a JSON request.

2

Express API

Validates the request and delegates classification.

3

Ollama LLM

Returns a category and confidence in strict JSON.

4

MongoDB

Optionally stores successful results for history.

API contract

POST /api/classify
Content-Type: application/json

{
  "text": "My order arrived damaged."
}

{
  "category": "Complaint",
  "confidence": 0.96
}

Classification definitions

  • Complaint: dissatisfaction or a reported problem.
  • Query: a question or request for information.
  • Feedback: an opinion, suggestion, praise, or review.
  • Other: text outside the defined categories.

Reliability safeguards

  • Rejects empty input and text over 5,000 characters.
  • Validates AI categories against an allow-list.
  • Clamps confidence between 0 and 1.
  • Uses a deterministic temperature of 0.
  • Returns consistent JSON errors.
